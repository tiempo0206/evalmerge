# Project journals

These journals provide a dated, auditable record of the work completed across
the three repositories involved in EvalMerge. Add a new date at the top of the
relevant journal whenever work is performed.

- [Inspect AI](inspect-ai.md): evaluation design, execution, and log handling
- [Automerge](automerge.md): CRDT research, integration, and upstream work
- [EvalMerge](evalmerge.md): the standalone integration project

Each daily entry records completed steps, verification evidence, decisions, and
the next concrete tasks. This makes the development process useful for both
learning and portfolio review.

Copy [`daily-template.md`](daily-template.md) when starting a new development
day, then move the newest dated entry to the top of the relevant journal.
